# One-Man-Jam-Band-Studio

AI-assisted, local-first music production studio for turning raw guitar performances into complete arrangements while preserving the untouched original recording.

## Current goals
- Live chromatic tuner
- Import/record raw guitar audio
- Key, tempo, pitch-center and chord-analysis hooks
- Detect speech/non-musical interruptions before arrangement generation
- Non-destructive project model
- Independent bass, drums and lead tracks
- Mix/master controls
- WAV/MP3 export
- Optional AI rendering backend later; core studio remains usable locally

## Safety / ownership
- Original audio is never overwritten.
- Raw recordings are not committed to this repository.
- Generated assets belong in local project storage or an approved private backend.

## Development status
Initial product skeleton. Browser-local functionality first, remote rendering second.
